# 📚 Library Management System

A beginner-friendly Library Management System built with Python.

This project was created to practice Python Object-Oriented Programming (OOP), user input, lists, loops, exception handling, and menu-based programs.

## 🚀 Features

- 📖 Display available books
- ➕ Add new books
- 👤 Save library member name
- 📚 Borrow books
- ⏳ Set borrowing days
- 🔄 Return books
- ❌ Handle invalid user input
- 📋 Menu-based interface

## 🧠 Python Concepts Used

- Classes and Objects
- `__init__()` constructor
- Instance variables
- Methods
- Lists
- `for` loops
- `while` loops
- `if / elif / else`
- `try / except`
- User input
- String methods
- Git and GitHub
